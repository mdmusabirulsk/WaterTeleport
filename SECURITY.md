# Security Policy

The **WaterTeleport** team takes security and multiplayer integrity seriously. We appreciate your efforts to responsibly disclose any vulnerabilities.

---

## 🛡️ Supported Versions

Only the latest release targeting the currently supported Minecraft version receives active security patches.

| Version | Minecraft Version | Supported |
| :--- | :--- | :--- |
| `1.0.x` | `26.1.2` | :white_check_mark: Yes |
| `< 1.0.0` | Any | :x: No |

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability, item duplication exploit, or server crash vector within WaterTeleport, please do **NOT** open a public GitHub issue.

Instead, please report it via one of the following methods:

1. **GitHub Private Vulnerability Reporting**:
   - Navigate to the repository's **Security** tab.
   - Click **Report a vulnerability** to submit a confidential report.
2. **Email**:
   - If GitHub private reporting is unavailable, contact the project maintainers directly via email with `[SECURITY]` in the subject line.

### What to Include in Your Report
- A clear summary of the issue.
- Step-by-step instructions to reproduce the vulnerability.
- Proof of Concept (PoC) or video demonstration if applicable.
- Assessment of the exploit impact (e.g., item duplication, server denial of service, unauthorized movement).

---

## ⏱️ Response Timeline

- **Initial Acknowledgement**: Within 48 hours of receipt.
- **Triage & Assessment**: Within 5 business days.
- **Fix & Public Advisory**: Once a patch is developed, tested, and ready for release, a security advisory and patched binary will be published concurrently.
